# FinTrack – API Specification

## Overview
This document specifies the RESTful endpoints, request parameters, JSON request/response formats, status codes, and authentication requirements for the Java Servlet backend.

> **Status:** Pending Phase 3 (Backend Architecture & Servlet Implementation).

---

## Planned Endpoints Overview

- `POST /api/auth/register` - User registration
- `POST /api/auth/login` - User authentication & session establishment
- `POST /api/auth/logout` - Session invalidation
- `GET/POST /api/accounts` - Account listing and creation
- `GET/POST /api/transactions` - Transaction management
- `GET/POST /api/categories` - Category listing and creation
- `GET/POST /api/budgets` - Budget planning and limits
- `GET/POST /api/savings-goals` - Savings goals tracking
